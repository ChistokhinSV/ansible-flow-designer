# Core tasks: baseline (0.23.x)

Steps counted from the UI as it is (pointer actions and key presses; typing a name counts as one
step). "Keyboard only" says whether the task can be done without a pointer.

| #   | Task                                 | Steps today (pointer)                                                                                                                                                                  | Keyboard only                                                                                    | Where it hurts                                                                                      |
| --- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| 1   | Add a step after another             | 4: click the `ok_hosts` port, _Add next node…_, type the title, Enter                                                                                                                  | yes: Tab to the node, Shift+F10, _Add next node…_, type, Enter (6)                               | the port must be found and hit at the zoom the canvas opens with                                    |
| 2   | Wire a failure path                  | 2: click the open fail port, pick a pattern (e.g. _Notify on-call and stop_)                                                                                                           | yes: Shift+F10 on the node, the port's submenu, the pattern (4)                                  | patterns from the palette need the target node selected first, which is explained only in a tooltip |
| 3   | Bind a module and set two parameters | 8: select, gear, _Implementation_ tab, type a search, pick the result, find parameter 1 under _More parameters_, set it, the same for parameter 2, _Save binding_ (9 with parameter 2) | partly: every field is reachable with Tab, but the result list and the docs table need many Tabs | parameters cannot be added from the docs table; the page covers the whole canvas                    |
| 4   | Set become and serial on a step      | 5: select, gear, _Execution_ tab, tick become, type serial                                                                                                                             | yes (with Tab)                                                                                   | the Execution tab is a flat list of ten fields                                                      |
| 5   | Edit a step inside a subflow         | 3: double-click the subflow, select the step, edit in the inspector                                                                                                                    | yes: Enter opens the subflow, Tab to the step, Tab to the field                                  | the panel showed the whole flow until AFD-30                                                        |
| 6   | Leave an open port open on purpose   | 4: click the port, _Leave open on purpose…_, type the reason, _Leave open_                                                                                                             | yes (Shift+F10, the port's submenu)                                                              | the same mechanism has three names and dialogs (open on purpose, Mark expected, Ignore)             |
| 7   | Run a check and find the failed step | 3 + search: _Run as skeleton_, Enter on the inputs prompt, _Run_ mode, then scan the canvas (and each subflow) for the failed step                                                     | partly: the run starts from the keyboard; finding the step needs the pointer                     | no list of failed steps that jumps to them; failures inside subflows need drilling                  |
| 8   | Find a step by name                  | no direct way: pan, zoom and open subflows until it is seen                                                                                                                            | no                                                                                               | no find, no minimap; large imported levels open at zoom 0.5                                         |

Pick mode ("Connect to another node…", "Rewire to another node…") ends only with a click on a
node, so wiring to a chosen node is pointer-only.
