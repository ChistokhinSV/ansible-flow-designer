# The user guide

Everything the designer does, as short pages. They open in VS Code's Markdown preview: run
**Ansible Flow: Open User Guide** from the Command Palette, or pick _User guide_ in the designer's
"…" menu.

**Tutorials**, start to finish:

1. Your first flow: steps, failure handling, a subflow, a skeleton run (15 minutes)
2. From design to production: modules, data between steps, polling, a real run
3. AWX end to end: templates, approvals, Run mode, import
4. Build flows with an AI assistant

**How-to pages** for one feature each: the canvas and shortcuts, ports and failure patterns,
subflows, decisions and parallel branches, binding, data between steps, polling, approvals, code
generation, runs and environments, Code mode, lenses, copy and paste, hand-written YAML,
AI assistants, AWX, import, settings.

**Reference:** commands, settings, problem codes, the flow file format, troubleshooting.
